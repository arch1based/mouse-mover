# 🖱️ Mouse Mover - Αυτόματος Βοηθός E-Learning

Πρόγραμμα που προσομοιώνει ανθρώπινη δραστηριότητα σε πλατφόρμες e-learning.

---

## 📦 Εκδόσεις

| Έκδοση | Αρχείο | Περιγραφή |
|--------|--------|-----------|
| Pro | `mouse_mover_pro.py` | Σταθερή έκδοση με αποθήκευση ρυθμίσεων |
| V3 | `mouse_mover_v3.py` / `MouseMoverV3.exe` | Νέα έκδοση με Bezier κίνηση & Anti-Bot |

---

## 🚀 Εγκατάσταση (για .py αρχεία)

### 1. Εγκατάσταση Python
- Κατέβασε από το [python.org/downloads](https://python.org/downloads)
- **Σημαντικό:** Τσέκαρε το "Add Python to PATH" κατά την εγκατάσταση

### 2. Εγκατάσταση βιβλιοθηκών
Άνοιξε CMD και γράψε:
```
pip install pyautogui keyboard
```

### 3. Εκκίνηση
Διπλό κλικ στο `.py` αρχείο ή από CMD:
```
python mouse_mover_v3.py
```

---

## ⚡ Χρήση EXE (χωρίς Python)

1. Κατέβασε το `MouseMoverV3.exe`
2. Διπλό κλικ για εκκίνηση
3. Πάτα **⚙ Ρυθμίσεις Συντεταγμένων**
4. Για κάθε σημείο πάτα **🎯 Καταγραφή** και βάλε το ποντίκι στο σωστό σημείο μέσα σε 5 δευτερόλεπτα
5. Πάτα **💾 Αποθήκευση** — αποθηκεύεται αυτόματα στο `mover_config.json`
6. Βάλε τις ώρες shutdown (π.χ. `5.5`)
7. Πάτα **START**

> ⚠️ **Σημαντικό:** Το `MouseMoverV3.exe` και το `mover_config.json` πρέπει να βρίσκονται στον **ίδιο φάκελο**!
> Αν μετακινήσεις το EXE, μετακίνησε και το config μαζί του.

### Πρώτη εκκίνηση — Σειρά ρύθμισης:
| Βήμα | Τι κάνεις |
|------|-----------|
| 1 | Άνοιξε την πλατφόρμα e-learning στον browser |
| 2 | Άνοιξε το `MouseMoverV3.exe` |
| 3 | Πάτα ⚙ Ρυθμίσεις και κατέγραψε όλα τα σημεία |
| 4 | Δοκίμασε με τα κουμπιά Test (Next, Λίστα, Refresh, Logout) |
| 5 | Βάλε ώρες και πάτα START |

---

## ⚙️ Ρύθμιση Συντεταγμένων

1. Άνοιξε το πρόγραμμα
2. Πάτα **⚙ Ρυθμίσεις Συντεταγμένων**
3. Για κάθε σημείο:
   - Πάτα **🎯 Καταγραφή**
   - Έχεις **5 δευτερόλεπτα** να πας το ποντίκι στο σωστό σημείο
4. Πάτα **💾 Αποθήκευση**

### Σημεία που χρειάζονται:
| Σημείο | Περιγραφή |
|--------|-----------|
| MENU Κορυφή | Πρώτη καρτέλα της λίστας μαθημάτων |
| MENU Πάτος | Τελευταία καρτέλα της λίστας |
| NEXT | Κουμπί "Επόμενο" |
| PLAY | Κουμπί Play του video |
| REFRESH | Κουμπί ανανέωσης του browser (⟳) |
| PROFILE | Εικονίδιο χρήστη (πάνω δεξιά) |
| LOGOUT | Κουμπί αποσύνδεσης |

## 🎮 Πλήκτρα

| Πλήκτρο | Λειτουργία |
|---------|-----------|
| F9 | Άμεσο κλικ NEXT |
| F8 | Άμεση δραστηριότητα λίστας |
| F7 | Άμεσο Refresh |
| Ποντίκι στη γωνία | Άμεσο σταμάτημα |

---

## ✨ Χαρακτηριστικά V3

- **Bezier κίνηση** — φυσική καμπύλη τροχιά αντί ευθείας γραμμής
- **Anti-Bot** — τυχαίες ταχύτητες και μικρο-κινήσεις
- **Auto Refresh** — ανανεώνει κάθε 45-55 λεπτά για να μην κλείσει το session
- **Auto Logout** — αποσύνδεση 3 λεπτά πριν το shutdown
- **Auto Shutdown** — κλείνει τον υπολογιστή μετά από X ώρες
- **Αποθήκευση ρυθμίσεων** — θυμάται τις συντεταγμένες

---

## ⚠️ Σημειώσεις

- Αν αλλάξεις zoom στον browser, πρέπει να ξαναρυθμίσεις τις συντεταγμένες
- Το πρόγραμμα πρέπει να τρέχει με την πλατφόρμα ανοιχτή
- Για 2η οθόνη οι συντεταγμένες είναι διαφορετικές
