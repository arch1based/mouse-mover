## 🆕 V4.1 — Για πλατφόρμες PDF / Slides

Χρησιμοποίησε το **V4.1** αν η πλατφόρμα σου έχει:
- Slides / PDF (όχι βίντεο)
- Κουμπί **≡** που ανοίγει πλαϊνή λίστα slides

### Πρώτη ρύθμιση V4.1
| Βήμα | Τι κάνεις |
|------|-----------|
| 1 | Άνοιξε την πλατφόρμα e-learning στον browser |
| 2 | Άνοιξε το `MouseMoverV4.exe` |
| 3 | Πάτα **⚙ Ρυθμίσεις Συντεταγμένων** |
| 4 | Για κάθε σημείο πάτα **🎯 Καταγραφή** και βάλε το ποντίκι εκεί μέσα σε 5 δευτερόλεπτα |
| 5 | Πάτα **💾 Αποθήκευση** |
| 6 | Δοκίμασε με τα κουμπιά **Test** |
| 7 | Ρύθμισε τις **Επιλογές** (checkboxes) |
| 8 | Βάλε τις ώρες shutdown και πάτα **START** |

### ⚙️ Σημεία ρύθμισης V4.1

| Σημείο | Περιγραφή |
|--------|-----------|
| NEXT | Κουμπί "NEXT ▶" κάτω δεξιά |
| PLAY | Κουμπί ▶ στον player (πατιέται μετά το Refresh) |
| LIST (≡) | Κουμπί ≡ που ανοίγει/κλείνει τη λίστα slides |
| SLIDE Πάνω | Το **πρώτο** slide μέσα στη λίστα (αφού ανοίξει) |
| SLIDE Κάτω | Το **τελευταίο** slide μέσα στη λίστα |
| REFRESH | Κουμπί ⟳ πάνω αριστερά στον browser |
| PROFILE | Εικονίδιο χρήστη πάνω δεξιά |
| LOGOUT | Εμφανίζεται μετά κλικ στο Profile |

> 💡 **SLIDE Πάνω/Κάτω**: Το πρόγραμμα θα κλικάρει σε τυχαίο σημείο ανάμεσά τους για να επιλέξει slide. Αν δεν τα ρυθμίσεις, η λίστα απλώς ανοίγει και κλείνει.

### ✅ Επιλογές (Checkboxes) V4.1

| Checkbox | Τι κάνει |
|----------|----------|
| ▶ NEXT κλικ | Πατάει το κουμπί NEXT κάθε 2-5 λεπτά |
| ☰ Λίστα (≡) | Ανοίγει ≡ → επιλέγει τυχαίο slide → κλείνει ≡ |
| ↻ Refresh | Ανανεώνει τον browser κάθε 45-55 λεπτά |
| ▶ Play μετά Refresh | Πατάει Play αφού κάνει refresh |

## ✨ Χαρακτηριστικά

- **Bezier κίνηση** — φυσική καμπύλη τροχιά αντί ευθείας γραμμής
- **Anti-Bot** — τυχαίες ταχύτητες και μικρο-κινήσεις κάθε 30 δευτ.
- **Auto Refresh** — ανανεώνει κάθε 45-55 λεπτά για να μην κλείσει το session
- **Auto Logout** — αποσύνδεση 3 λεπτά πριν το shutdown
- **Auto Shutdown** — κλείνει τον υπολογιστή μετά από X ώρες
- **Αποθήκευση ρυθμίσεων** — θυμάται τις συντεταγμένες
- **Checklist ενεργειών** (V4.1) — επιλέγεις ποιες ενέργειες θα εκτελούνται
